Understanding Internet Speed

Internet speeds are commonly displayed using megabits per second (Mbps), while file transfer speeds are often displayed using megabytes per second (MBps).

1 Byte = 8 Bits
1 MBps = 8 Mbps
1 GBps = 8 Gbps
